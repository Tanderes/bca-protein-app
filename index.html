Browser-based Pierce BCA microplate analysis — upload two CSVs, get a standard curve, interpolated concentrations, and an interactive box plot. No data leaves your machine.

Input file format
  • Both CSVs: rows A–H in col 1, cols 1–12 in header
  • Absorbance file — raw plate reader values
  • Layout file — sample name per well; standard wells labelled STD
  • Standard curve read from the row set in config (default: row H)
How it works
1
Blank correction — mean A₀ subtracted from every well
2
Linear regression — least-squares fit on blank-corrected standards
3
Interpolation — conc = slope × (abs − blank) + intercept × dilution factor
4
Box plot — per-well values, parent strain sets dashed reference
Config settings
  • Wavelength — measurement wavelength (nm), default 526
  • Dilution factor — multiplier for all concentrations
  • Standards in row — which row holds BSA standards
  • Std concentrations — comma-separated µg/mL, must include 0
  • Parent strain — dashed reference line on box plot
Test data — 20260522 Y293 PDIs

Y293 yeast strains expressing PDI variants. Standards in row H (all 12 wells = STD).

  • Rows A–C — colony 1 replicates (c1)
  • Rows D–F — colony 2 replicates (c2)
  • Row G — controls: Y11, Y243, Y310, Y371
  • Expected: R² ≥ 0.99, ~500–700 µg/mL, Y293 ~600 µg/mL
