BCA Protein App
Protocol GitHub

A browser-based tool for analysing Pierce BCA microplate protein assays. Upload two CSVs — absorbance readings and a plate layout map — and the app fits a BSA standard curve, interpolates protein concentrations for every sample well, and renders an interactive box plot grouped by strain. No server, no installation, no data leaves your machine.

Input file format
  • Both CSVs must use rows A–H in column 1 and columns 1–12 in the header — standard 96-well grid
  • Absorbance file — raw plate reader values, one per well
  • Layout file — sample name per well; standard curve wells labelled STD
  • Standard curve is read from the row set in Standards in row (default: row H, last row)
  • Empty wells can be left blank in the layout file
How it works
1
Blank correction — mean A₀ subtracted from every well
2
Linear regression — least-squares fit on blank-corrected standards (0 µg/mL excluded)
3
Interpolation — conc = slope × (abs − blank) + intercept, × dilution factor
4
Statistics — mean, SD, CV per sample across all replicate wells
5
Box plot — per-well values, IQR box, median, whiskers, individual dots; parent strain sets dashed reference line
Config settings
  • Wavelength — plate reader measurement wavelength (nm). Default 526.
  • Dilution factor — multiplier applied to all concentrations. Use 1 for undiluted.
  • Standards in row — which plate row holds BSA standards. Default H.
  • Std concentrations — comma-separated µg/mL values left-to-right; must include a 0 for blank.
  • Parent strain — sets the dashed reference line and grey colour group on the box plot.
Test data — 20260522 Y293 PDIs

BCA assay measuring protein concentration in Y293 yeast strains expressing PDI variants. Standard curve in row H (all 12 wells = STD).

  • Rows A–C — Y293+EBB769–797 colony 1 (c1) replicates
  • Rows D–F — Y293+EBB769–797 colony 2 (c2) replicates
  • Row G — control strains: Y11, Y243, Y310, Y371
  • Row H — BSA standards: 2000, 1500, 1000, 750, 500, 250, 125, 25, 0 µg/mL
  • Expected output: R² ≥ 0.99, concentrations ~500–700 µg/mL, parent Y293 ~600 µg/mL
